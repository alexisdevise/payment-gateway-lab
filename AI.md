## Generation notes (2026-11-19 — bootstrap session)

During the initial generation pass, the following issues surfaced and were resolved before completing the test suite:
- Non-constant `ConsumerPrincipal.class.getName()` used inside `@RequestAttribute` (replaced with a literal).
- Ambiguous bean injection between the PSP router and sandbox connector (resolved with `@Primary` and a dedicated
  `PspConnector` interface).
- Refund replay initially returned `200` on a previously declined refund instead of re-raising `psp_declined`.
- Nested Spring Data repository interfaces were ignored by component scanning (moved to top-level interfaces).
- Testcontainers bumped from `1.20.x` to `1.21.x` for compatibility with Docker Engine `29.9`.
